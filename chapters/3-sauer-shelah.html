3. The Sauer–Shelah Lemma

$\tau_{\mathcal{H}}(m) = \max_{C \subseteq \mathcal{X},\, |C| = m} |\mathcal{H}_C|$.

Always $\tau_{\mathcal{H}}(m) \le 2^m$, with equality exactly when some $m$-point set is shattered, so equality holds iff $m \le \mathrm{VCdim}(\mathcal{H})$. The surprise: once $m$ passes the VC dimension, the growth function is only polynomial.

If $\mathrm{VCdim}(\mathcal{H}) \le d$, then for all $m$, $$\tau_{\mathcal{H}}(m) \le \sum_{i=0}^{d} \binom{m}{i}, \qquad\text{and for } m \ge d,\quad \sum_{i=0}^{d}\binom{m}{i} \le \left(\frac{em}{d}\right)^d.$$

See it: exponential vs. polynomial

The y-axis is logarithmic, so $2^m$ is a straight line. The bound matches $2^m$ up to $m = d$, then bends away.
