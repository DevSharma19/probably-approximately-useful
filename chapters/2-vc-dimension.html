Instead of counting hypotheses, count how many different behaviors $\mathcal{H}$ can show on a finite set of points.

For $C = \{c_1,\dots,c_m\} \subseteq \mathcal{X}$, the restriction of $\mathcal{H}$ to $C$ is $\mathcal{H}_C = \{ (h(c_1),\dots,h(c_m)) : h \in \mathcal{H} \} \subseteq \{0,1\}^m$.
$\mathcal{H}$ shatters $C$ if $|\mathcal{H}_C| = 2^{|C|}$, meaning every labeling of $C$ is achieved by some $h \in \mathcal{H}$.
$\mathrm{VCdim}(\mathcal{H})$ is the size of the largest set shattered by $\mathcal{H}$, or $\infty$ if $\mathcal{H}$ shatters arbitrarily large sets.

To show $\mathrm{VCdim}(\mathcal{H}) = d$, you must show both: (1) some set of size $d$ is shattered, and (2) no set of size $d+1$ is shattered.

Try it: the shattering game

Place points and pick a class. The widget checks all $2^n$ labelings. Can you find the largest set each class shatters? Can you convince yourself that no larger set works?
