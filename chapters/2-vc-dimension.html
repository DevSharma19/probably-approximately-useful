2. Shattering & VC Dimension

A learner only sees finitely many points. So what matters is how many ways $\mathcal{H}$ can label a finite set, not how many hypotheses it has.

For $C = \{c_1,\dots,c_m\} \subseteq \mathcal{X}$, the restriction of $\mathcal{H}$ to $C$ is $\mathcal{H}_C = \{ (h(c_1),\dots,h(c_m)) : h \in \mathcal{H} \} \subseteq \{0,1\}^m$.

Example: thresholds on $C = \{1, 2, 3\}$ give $\mathcal{H}_C = \{000, 001, 011, 111\}$. That is 4 labelings out of 8.

$\mathcal{H}$ shatters $C$ if $|\mathcal{H}_C| = 2^{|C|}$. That is, every labeling of $C$ is achieved by some $h \in \mathcal{H}$.

If $\mathcal{H}$ shatters $C$, labels on part of $C$ say nothing about labels on the rest. Chapter 5 turns this into a lower bound.

$\mathrm{VCdim}(\mathcal{H})$ is the size of the largest set shattered by $\mathcal{H}$. If $\mathcal{H}$ shatters sets of every size, $\mathrm{VCdim}(\mathcal{H}) = \infty$.

To show $\mathrm{VCdim}(\mathcal{H}) = d$, prove two things:

  1. Some set of size $d$ is shattered.
  2. No set of size $d+1$ is shattered.

The shattering game

Place points and pick a class. The widget checks all $2^n$ labelings.

  • Find 4 points that rectangles shatter. Then add a fifth.
  • Find 3 points that halfplanes shatter. Why do 4 points always fail?
  • Place 7 points on a circle and select convex polygons.

Examples

Each class below is described by a few real parameters. Thresholds have one parameter, $t$. Intervals have two, $a$ and $b$. Halfplanes have three: $w_1$, $w_2$, and $b$. Rectangles have four. In each case the VC dimension equals the number of parameters. This suggests that VC dimension counts the degrees of freedom of a class. Convex polygons have no bound on their number of vertices, and their VC dimension is infinite. The last example shows that the parameter count can still be misleading.

$\mathcal{H} = \{x \mapsto \mathbb{1}[x \ge t] : t \in \mathbb{R}\}$.
Proof

Shattered: $\{0\}$. Use $t = -1$ for label 1 and $t = 1$ for label 0.

Not shattered: take $x_1 < x_2$. If $h_t(x_1) = 1$ then $x_2 > x_1 \ge t$, so $h_t(x_2) = 1$. The labeling $(1, 0)$ is impossible. $\blacksquare$

$\mathcal{H} = \{x \mapsto \mathbb{1}[a \le x \le b] : a, b \in \mathbb{R}\}$.
Proof

Shattered: $\{1, 2\}$. Use $[1,1]$, $[2,2]$, $[1,2]$, and $[5,5]$.

Not shattered: take $x_1 < x_2 < x_3$. An interval that contains $x_1$ and $x_3$ contains $x_2$. The labeling $(1, 0, 1)$ is impossible. $\blacksquare$

$\mathcal{H} = \{x \mapsto \mathbb{1}[\langle w, x\rangle \ge b] : w \in \mathbb{R}^2, b \in \mathbb{R}\}$.

More generally, halfspaces in $\mathbb{R}^d$ have VC dimension $d+1$.

$\mathcal{H}$ is the set of indicators of rectangles $[a_1, b_1] \times [a_2, b_2]$ in $\mathbb{R}^2$.
Proof

Shattered: the diamond $\{(0,1), (0,-1), (1,0), (-1,0)\}$. For a subset $T$, use the bounding box of $T$. The box contains no other diamond point. For $T = \emptyset$, use an empty rectangle ($a_1 > b_1$).

Not shattered: take any 5 points. Pick a leftmost, rightmost, topmost, and bottommost point. That is at most 4 points, so some point $p$ is left over. Label the chosen points 1 and $p$ label 0. Any rectangle containing the chosen points contains their bounding box. That box contains $p$. So this labeling is impossible. $\blacksquare$

$\mathcal{H}$ is the set of indicators of convex polygons in $\mathbb{R}^2$.

VC dimension is not the number of parameters

$\mathcal{H} = \{x \mapsto \mathbb{1}[\sin(\theta x) > 0] : \theta \in \mathbb{R}\}$ on $\mathcal{X} = \mathbb{R}$ has VC dimension $\infty$.
Proof

Take $x_i = 2^{-i}$ for $i = 1, \dots, m$ and any labels $y_1, \dots, y_m$. Set $$\theta = \pi\Big(1 + \sum_{j=1}^{m} (1 - y_j)\, 2^j\Big).$$ Write $\theta x_i = \pi u_i$ with $u_i = 2^{-i}\big(1 + \sum_j (1-y_j) 2^j\big)$. The integer part of $u_i$ is $\sum_{j \ge i} (1-y_j) 2^{j-i}$. Its parity is $1 - y_i$. The fractional part is $2^{-i}\big(1 + \sum_{j < i}(1-y_j)2^j\big)$, which lies strictly between 0 and 1. So $\sin(\pi u_i) > 0$ exactly when the integer part is even, that is, when $y_i = 1$. $\blacksquare$
