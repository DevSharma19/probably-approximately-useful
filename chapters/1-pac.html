1. Learning from Samples

The setup

A domain $\mathcal{X}$, labels $\{0,1\}$, and an unknown distribution $\mathcal{D}$ over labeled examples $\mathcal{X} \times \{0,1\}$. The learner sees a sample $S = ((x_1, y_1), \dots, (x_m, y_m))$ drawn i.i.d. from $\mathcal{D}$, and outputs a hypothesis $h : \mathcal{X} \to \{0,1\}$. It chooses $h$ from a fixed hypothesis class $\mathcal{H}$.

The learner does not know $\mathcal{D}$. It only sees $S$.

$L_{\mathcal{D}}(h) = \Pr_{(x,y) \sim \mathcal{D}}[h(x) \neq y]$ and $L_S(h) = \frac{1}{m}\left|\{ i : h(x_i) \neq y_i\}\right|$.

$L_{\mathcal{D}}(h)$ is what we care about. $L_S(h)$ is what the learner can compute.

There exists $h^\star \in \mathcal{H}$ with $L_{\mathcal{D}}(h^\star) = 0$.

Some hypothesis in the class labels everything correctly. Then $L_S(h^\star) = 0$ with probability 1. Chapters 1–3 assume realizability. Chapter 4 drops it.

A hypothesis class $\mathcal{H}$ is PAC learnable if there exist a function $m_{\mathcal{H}} : (0,1)^2 \to \mathbb{N}$ and a learning algorithm $A$ such that for every $\varepsilon, \delta \in (0,1)$ and every distribution $\mathcal{D}$ over $\mathcal{X} \times \{0,1\}$ for which the realizability assumption holds: given $m \ge m_{\mathcal{H}}(\varepsilon,\delta)$ i.i.d. examples from $\mathcal{D}$, $A$ outputs $h$ with $$\Pr_{S \sim \mathcal{D}^m}\big[L_{\mathcal{D}}(h) \le \varepsilon\big] \ge 1 - \delta.$$

The definition has three parts.

  • Approximately correct: the error is at most $\varepsilon$.
  • Probably: this holds with probability at least $1 - \delta$. Some failure is unavoidable. For example, every sample point could be the same $x$.
  • Distribution-free: one function $m_{\mathcal{H}}$ works for every $\mathcal{D}$. The sample size cannot depend on $\mathcal{D}$.
The smallest valid $m_{\mathcal{H}}$ is the sample complexity of $\mathcal{H}$.

The role of $\delta$ matches the error probability of a randomized algorithm in RP or BPP.

Empirical Risk Minimization

$\mathrm{ERM}_{\mathcal{H}}$ outputs any $h \in \mathcal{H}$ that minimizes $L_S(h)$. Under realizability, $L_S(h^\star) = 0$, so ERM outputs some $h$ with $L_S(h) = 0$. Such an $h$ is consistent with $S$.

Let $\mathcal{H}$ be finite. Under realizability, ERM is a PAC learner with sample complexity $$m_{\mathcal{H}}(\varepsilon,\delta) \le \left\lceil \frac{\ln(|\mathcal{H}|/\delta)}{\varepsilon} \right\rceil.$$
Proof

Call $h$ bad if $L_{\mathcal{D}}(h) > \varepsilon$. Let $\mathcal{H}_B$ be the set of bad hypotheses. ERM fails only if some bad $h$ is consistent with $S$.

Fix a bad $h$. Each example is labeled correctly by $h$ with probability $1 - L_{\mathcal{D}}(h) < 1 - \varepsilon$. The examples are independent, so $$\Pr[L_S(h) = 0] \le (1-\varepsilon)^m \le e^{-\varepsilon m}.$$

By the union bound over $\mathcal{H}_B$, $$\Pr[\text{ERM fails}] \le |\mathcal{H}_B|\, e^{-\varepsilon m} \le |\mathcal{H}|\, e^{-\varepsilon m}.$$ This is at most $\delta$ when $m \ge \ln(|\mathcal{H}|/\delta)/\varepsilon$. $\blacksquare$

If each hypothesis is described by $b$ bits, then $|\mathcal{H}| \le 2^b$ and $m = O\big((b + \log(1/\delta))/\varepsilon\big)$ samples suffice.

The sample cost grows with description length.

Now, consider thresholds on $\mathbb{R}$: $h_t(x) = \mathbb{1}[x \ge t]$ for $t \in \mathbb{R}$. This class is infinite, so the bound above says nothing. Therefore, $\ln|\mathcal{H}|$ is the wrong measure of size. Chapter 2 defines the right one.
