4. Uniform Convergence

Dropping realizability

Now, we will remove the realizability assumption. No hypothesis in $\mathcal{H}$ may be perfect. We can no longer ask for error $\le \varepsilon$. Instead, we ask to be nearly as good as the best hypothesis in the class.

$\mathcal{H}$ is agnostic PAC learnable if there exist $m_{\mathcal{H}} : (0,1)^2 \to \mathbb{N}$ and an algorithm $A$ such that for every $\varepsilon, \delta \in (0,1)$ and every distribution $\mathcal{D}$ over $\mathcal{X} \times \{0,1\}$: given $m \ge m_{\mathcal{H}}(\varepsilon,\delta)$ i.i.d. examples from $\mathcal{D}$, $A$ outputs $h$ with $$\Pr_{S \sim \mathcal{D}^m}\Big[L_{\mathcal{D}}(h) \le \min_{h' \in \mathcal{H}} L_{\mathcal{D}}(h') + \varepsilon\Big] \ge 1 - \delta.$$

Clearly, when realizability holds, $\min_{h'} L_{\mathcal{D}}(h') = 0$ and this is exactly PAC learnability from Chapter 1.

Uniform convergence

Recall that ERM chooses the hypothesis with the smallest error. This is a good choice only if empirical error is a good estimate of true error. Specifically, we need $L_S(h)$ to be close to $L_{\mathcal{D}}(h)$ for every $h \in \mathcal{H}$. We require this property over all $h$ since ERM's choice depends on $S$. A sample with this property is called representative.

$S$ is $\varepsilon$-representative if $|L_S(h) - L_{\mathcal{D}}(h)| \le \varepsilon$ for all $h \in \mathcal{H}$.

Moreover, we say a class has the uniform convergence property if, for every distribution $\mathcal{D}$, a large enough sample is representative with high probability. "Uniform" means the guarantee holds for all of $\mathcal{H}$ at once.

$\mathcal{H}$ has the uniform convergence property if there is $m^{UC}_{\mathcal{H}}(\varepsilon,\delta)$ such that for every $\mathcal{D}$, a sample of size $m \ge m^{UC}_{\mathcal{H}}(\varepsilon,\delta)$ is $\varepsilon$-representative with probability at least $1-\delta$.
If $S$ is $\tfrac{\varepsilon}{2}$-representative, then any ERM output $h_S$ satisfies $L_{\mathcal{D}}(h_S) \le \min_{h\in\mathcal{H}} L_{\mathcal{D}}(h) + \varepsilon$.
Proof

Let $h$ be any element of $\mathcal{H}$. Then $$\begin{aligned}L_{\mathcal{D}}(h_S) &\le L_S(h_S) + \tfrac{\varepsilon}{2} \\ &\le L_S(h) + \tfrac{\varepsilon}{2} \\ &\le L_{\mathcal{D}}(h) + \varepsilon.\end{aligned}$$ The first and third steps use representativeness. The second uses that $h_S$ minimizes $L_S$. Take the minimum over $h$. $\blacksquare$

So if $\mathcal{H}$ has the uniform convergence property, ERM is an agnostic PAC learner with $m_{\mathcal{H}}(\varepsilon,\delta) \le m^{UC}_{\mathcal{H}}(\varepsilon/2, \delta)$. Take $m \ge m^{UC}_{\mathcal{H}}(\varepsilon/2,\delta)$. With probability at least $1-\delta$, $S$ is $\frac{\varepsilon}{2}$-representative, and the lemma applies.

From one hypothesis to the whole class

Fix $h$ before seeing $S$. Then $L_S(h)$ is an average of $m$ independent trials with mean $L_{\mathcal{D}}(h)$. By Hoeffding's inequality, $$\Pr\big[|L_S(h) - L_{\mathcal{D}}(h)| > \varepsilon\big] \le 2e^{-2m\varepsilon^2}.$$

This does not apply to ERM's output $h_S$, because $h_S$ is chosen to fit $S$. In the example from Chapter 1, $L_S(h_S) = 0$ but $L_{\mathcal{D}}(h_S) = 1$.

So we need the estimate to hold for every $h \in \mathcal{H}$ at once. Let $\mathcal{H}$ be finite. For each $h$, let $B_h$ be the event that $|L_S(h) - L_{\mathcal{D}}(h)| > \varepsilon$. The sample fails if some $B_h$ happens, that is, if the union $\bigcup_{h \in \mathcal{H}} B_h$ happens. The union bound says the probability of a union is at most the sum of the probabilities. Hoeffding bounds each term by $2e^{-2m\varepsilon^2}$, and there are $|\mathcal{H}|$ terms. So $$\begin{aligned}&\Pr\Big[\exists h \in \mathcal{H} : |L_S(h) - L_{\mathcal{D}}(h)| > \varepsilon\Big] \\ &\qquad\le \sum_{h \in \mathcal{H}} \Pr[B_h] \le 2|\mathcal{H}|\,e^{-2m\varepsilon^2}.\end{aligned}$$ This is at most $\delta$ when $m \ge \ln(2|\mathcal{H}|/\delta)/(2\varepsilon^2)$.

Let $\mathcal{H}$ be finite. Then $\mathcal{H}$ has the uniform convergence property with $$m^{UC}_{\mathcal{H}}(\varepsilon,\delta) \le \left\lceil \frac{\ln(2|\mathcal{H}|/\delta)}{2\varepsilon^2} \right\rceil.$$ So ERM is an agnostic PAC learner for $\mathcal{H}$ with $$\begin{aligned}m_{\mathcal{H}}(\varepsilon,\delta) &\le m^{UC}_{\mathcal{H}}(\varepsilon/2,\delta) \\ &\le \left\lceil \frac{2\ln(2|\mathcal{H}|/\delta)}{\varepsilon^2} \right\rceil.\end{aligned}$$

For infinite $\mathcal{H}$, the next section replaces $|\mathcal{H}|$ with the growth function.

Finite VC dimension ⇒ uniform convergence

The finite-class bound fails for infinite $\mathcal{H}$ because its union bound runs over infinitely many hypotheses. But most of those hypotheses are redundant on any given sample. Two hypotheses that label $S$ the same way have the same empirical error. So on a sample of size $m$, $\mathcal{H}$ shows at most $\tau_{\mathcal{H}}(m)$ distinct behaviors. Let $d = \mathrm{VCdim}(\mathcal{H})$. By Sauer–Shelah, that is at most $(em/d)^d$ once $m \ge d$. We would like to replace $|\mathcal{H}|$ in the union bound with this number.

For every $\mathcal{H}$, every $\mathcal{D}$, and every $m$ with $m\varepsilon^2 \ge 2$, $$\begin{aligned}&\Pr_{S \sim \mathcal{D}^m}\Big[\exists h \in \mathcal{H} : |L_S(h) - L_{\mathcal{D}}(h)| > \varepsilon\Big] \\ &\qquad\le 4\,\tau_{\mathcal{H}}(2m)\, e^{-m\varepsilon^2/8}.\end{aligned}$$

The proof is beyond the scope of this discussion. See Vapnik and Chervonenkis (1971), or Anthony and Bartlett (1999), Theorem 4.3.

Compare the two bounds on the probability that some $h$ is far from its true error: $$2\,|\mathcal{H}|\, e^{-2m\varepsilon^2} \qquad \text{versus} \qquad 4\,\tau_{\mathcal{H}}(2m)\, e^{-m\varepsilon^2/8}.$$ The constants are worse. But the size of the class, $|\mathcal{H}|$, is replaced by the number of behaviors on $2m$ points. When $d$ is finite, that number is polynomial in $m$, and the exponential term wins.

If $\mathrm{VCdim}(\mathcal{H}) = d < \infty$, then $\mathcal{H}$ has the uniform convergence property with $$m^{UC}_{\mathcal{H}}(\varepsilon,\delta) = O\!\left(\frac{d\log(1/\varepsilon) + \log(1/\delta)}{\varepsilon^2}\right).$$
Proof

By Sauer–Shelah, $\tau_{\mathcal{H}}(2m) \le (2em/d)^d$ for $2m \ge d$. The VC inequality's bound is at most $\delta$ when $$m \ge \frac{8}{\varepsilon^2}\Big(d\ln\frac{2em}{d} + \ln\frac{4}{\delta}\Big).$$ Here $m$ appears on both sides, but only inside a logarithm on the right. Solving gives the stated bound. $\blacksquare$

A finer argument (chaining) removes the $\log(1/\varepsilon)$ factor. This gives $O\big((d + \log(1/\delta))/\varepsilon^2\big)$, which is optimal.

Putting the pieces together

We now have every piece of one direction of the main theorem. Each chapter supplied one link:

  1. Chapter 2: VC dimension measures the size of a class by the largest set it shatters.
  2. Chapter 3: if the VC dimension is $d$, the growth function is at most $(em/d)^d$, a polynomial in $m$.
  3. Chapter 4: a polynomial growth function gives uniform convergence, by the VC inequality.
  4. Chapter 4: uniform convergence makes ERM an agnostic PAC learner, by the "Representative ⇒ ERM succeeds" lemma. Under realizability, the same learner is a PAC learner.

So finite VC dimension implies PAC learnability. This is the sufficiency half of the Fundamental Theorem.

The other half is necessity: if the VC dimension is infinite, no learner succeeds. Chapter 2 already contains the idea. If $\mathcal{H}$ shatters a set $C$, then labels on part of $C$ say nothing about the rest. Chapter 5 turns this into a proof, called the No Free Lunch theorem. It then combines both halves into the Fundamental Theorem.
